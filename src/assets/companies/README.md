# Company logos

Drop each company's logo in this folder and it appears automatically on the Experience cards.
PNG, SVG, WebP or JPG all work. Use a square-ish logo (transparent or white background is best).

Expected file names (lower-case):

| Company                          | File name                         |
|----------------------------------|-----------------------------------|
| Yaynuts                          | `yaynuts.png`                     |
| Universal Cartons Industry (LLC) | `universal-cartons-industry.png`  |
| Red Feather Tech                 | `red-feather-tech.png`            |
| XAutonomous                      | `xautonomous.png`                 |
| Skyfit International             | `skyfit-international.png`        |
| TechClone (Pvt) Ltd              | `techclone-ltd.png`               |
| Mark360                          | `mark360.png`                     |
| The Web Gateway                  | `the-web-gateway.png`             |
| Learning Pitch                   | `learning-pitch.png`              |
| EDLAB Pakistan                   | `edlab-pakistan.png`              |

Any company without a file keeps its colour monogram tile.
